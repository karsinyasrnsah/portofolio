# Portofolio Karsin Yasransah
Berbasis template Folio (HTML · Tailwind · Alpine.js) oleh Laurent Begey, lisensi MIT.

Buka `index.html` di browser (butuh internet untuk Tailwind/Alpine CDN).

Yang perlu kamu ganti sendiri di `index.html`:
- Foto: simpan `foto.jpg` di folder yang sama, lalu aktifkan baris `<img>` di bagian hero.
- Email & username GitHub di bagian Kontak.
